# Reviews

Where steering happens (see [SYSTEM](../SYSTEM.md)). Keep them short and honest.

- `weekly/YYYY-Www.md` — what landed, the week's artifact, next week's single focus.
- `monthly/YYYY-MM.md` — did the spine advance? advance a flagship; re-read the quarter's goal.
- `quarterly/YYYY-Qn.md` — the **gate check**: cleared gates + their artifacts, then edit [TRAJECTORY](../TRAJECTORY.md).
